# Project 3 - SQL Data Analysis

## Overview

This project focuses on performing SQL-based data analysis on a business transaction dataset.

SQLite and Python were used to execute SQL queries for extracting meaningful business insights.

---

# Tasks Performed

* Created SQLite database
* Executed SELECT queries
* Applied WHERE filtering
* Used GROUP BY and ORDER BY
* Performed COUNT, SUM, and AVG aggregations
* Generated customer and product insights
